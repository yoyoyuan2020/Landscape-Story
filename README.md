# LaViSa Lab 互動地圖與平台

東海大學 LaViSa Lab 原友蘭 製作

- [景觀故事群島](https://yoyoyuan2020.github.io/Landscape-Story/)：《景觀故事》課程學生 StoryMap 成果的立體群島入口（`index.html`）
- [山徑脈動 Forest Trace](https://yoyoyuan2020.github.io/Landscape-Story/forest-trace/)：森林步道新世代監測模式的故事地圖（`forest-trace/`）
- [林野感測站（暫名）](https://yoyoyuan2020.github.io/Landscape-Story/sensing/)：給森林遊憩第一線管理人員的新世代感測技術平台（`sensing/`）

所有頁面都是靜態 HTML，不需要伺服器。
