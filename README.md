# LaViSa Lab 互動地圖

東海大學 LaViSa Lab 原友蘭 製作

- [景觀故事群島](https://yoyoyuan2020.github.io/Landscape-Story/)：《景觀故事》課程學生 StoryMap 成果的立體群島入口（`index.html`）
- [山徑脈動 Forest Trace](https://yoyoyuan2020.github.io/Landscape-Story/forest-trace/)：森林步道新世代監測模式的故事地圖（`forest-trace/index.html`）

兩個頁面都是單一 HTML 檔，以 Three.js 繪製，不需要伺服器。
